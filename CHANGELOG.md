# Changelog

All notable changes to WebTester are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-15

First public release.

### Added
- Side-by-side panes for 40+ devices (phones, foldables, tablets, laptops, desktops, 4K and width breakpoints), custom devices, presets, rotation, and strip / grid / focus layouts with zoom.
- Real light and dark mode per pane, Chrome's forced dark mode, and one-click light-and-dark pairs.
- Synced scrolling, clicks, typing and form fields, keys, navigation and (optionally) hover across panes.
- Emulation of network speed, vision deficiencies, reduced motion, contrast, forced colours, print media, touch and user agent.
- A unified console with errors, warnings and logs from every pane, grouped by message and labelled by pane.
- Automatic checks for horizontal overflow and missing mobile viewport tags, with on-page markers.
- Inspect mode that highlights the same element in every pane, plus debug outlines.
- Screenshots: single pane, full page, or all panes in one labelled image.
- Workspaces, session restore, live reload on file changes, local file support and keyboard shortcuts.
- Windows installer and portable `.exe`, built and published automatically on every version tag.
